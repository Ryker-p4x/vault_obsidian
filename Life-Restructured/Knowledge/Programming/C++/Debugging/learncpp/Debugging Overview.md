### Debugging problems process:

For debugging any problems we'd usually follow these steps:
1. Find the problem.
2. Try to understand why this problem is ocurring.
3. Propose a solution to fix this problem.
4. Do the solution.
5. Retest to make sure the problem doesn't happen anymore.
6. Retest to make sure no new problems have appeared.

### Code inspection to find problems:

When trying to find a problem by code inspection, you need to first of all, search in the right section. However, when code gets more complex, a lot of things can happen:
1. You might not even get a lead
2. The code is obviously more complex so more lines of code to have to read through
3. Bugs can be made by making bad assumptions which are almost impossible to visually spot due to you most likely making the same bad assumption while reading the code.
One technique we can do is [[Watching the behaviour of a program]]
