It's a very good compiler that compiles C++ code and automatically links C++ libraries.
Some flags that we know are:
- -o name (for naming the executable file after)
- -lname_of_library (lets you link libraries)
- -g (used for debugging)
- -L: All libraries with -l tryna get linked will check in whatever path you input in here
- -I: If you can't find header files included then check whatever path you input in here.
