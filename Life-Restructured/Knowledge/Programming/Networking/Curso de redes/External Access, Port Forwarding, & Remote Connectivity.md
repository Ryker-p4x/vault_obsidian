- Manual Port Forwarding directs incoming traffic on specific public ports directly to internal local IP addresses.
    
- Dynamic DNS (DDNS) maps a persistent domain name to a dynamic public IP address that changes over time.
    
- Universal Plug and Play (UPnP) allows devices to open router ports automatically, though it introduces security risks.
    
- Demilitarized Zones (DMZ) expose all unforwarded incoming traffic directly to one local device, carrying high security risks.
    
- Reverse Connections initiate outbound connections to external relay servers to safely bypass restrictive firewalls without opening incoming ports.
