5- Ports act as virtual channel numbers that allow multiple applications to send and receive data on a single device simultaneously.
    
- A socket combines an IP address with a port number (e.g., `192.168.1.10:8080`) to form a specific communication endpoint.
    
- **Well-Known Ports (0–1023):** Reserved for system services like HTTP (80), HTTPS (443), and SSH (22).
    
- **Registered Ports (1024–49151):** Assigned to specific applications like media servers or databases.
    
- **Ephemeral Ports (49152–65535):** Temporary ports dynamically created by operating systems for short-term outbound connections.
