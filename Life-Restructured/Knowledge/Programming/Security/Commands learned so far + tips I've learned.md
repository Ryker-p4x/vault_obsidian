If you don't know how a command works you can use man --command

ssh - used to connect to a server through your local machine (very useful)
mv - used to rename files and also used to move them.
rm - used to remove files
cat - used to read files (very useful)
grep - used to read specific text on a file (need to review this)
mkdir - used to make folders
mktemp - used to make tmp directories (still not sure what tmp directories' main use is but wtv)

File types
.bz2: used bunzip2 to decompress a file
.gz: used gunzip to decompress a file
.tar: used tar command to decompress a file

Most important thing about commands so far is to understand the flags so always try to see if there's any flags that can assist you in a task.
